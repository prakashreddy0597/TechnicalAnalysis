## What this stage does

1. Reads `portfolio.txt`, one symbol per line: AAPL, MSFT and GOOGL.
2. Imports historical OHLCV and adjusted close using `quantmod::getSymbols()`.
3. Stores each symbol as a separate data frame in a named list and exports its raw CSV.
4. Calculates mean, median, numerical mode handling, sample standard deviation and a trailing five-trading-session simple moving average using adjusted close.
5. Prints previews and statistics, writes a summary CSV, and generates a chart for each stock.

The inclusive requested period is January 1–March 31, 2024. The downloaded observations are January 2–March 28, 2024. Weekends and market holidays are not inserted as artificial records.

## Method definitions

- Price variable: **Adjusted**, in USD, not the raw unadjusted Close.
- Mean and median: all finite adjusted closes in the requested period.
- Standard deviation: sample SD, using the denominator `n - 1`. This is dispersion of price levels, not return volatility.
- Mode: values with the highest exact numerical frequency. If all values occur once, report that there is no unique mode rather than misusing base R's `mode()`, which describes storage type. Any tied recurring modes are all returned.
- SMA: trailing arithmetic mean of five complete observed trading sessions. The first four values are `NA` by construction. There is no future-looking centering.
- Missing adjusted closes: explicitly excluded and counted; no interpolation or forward fill is performed. No missing adjusted-close observations occurred in the executed snapshot.
